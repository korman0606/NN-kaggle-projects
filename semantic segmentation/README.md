# Land Use Semantic Segmentation (Estonia)

Решение задачи семантической сегментации (5 классов) с использованием U-Net на основе ResNet50.

## Результаты
- **mIoU на валидации**: 0.71
- **mIoU на тесте**: ~0.70

## Структура
- `src/` – исходный код
- `outputs/` – графики и визуализации
- `notebooks/` – исследование данных
