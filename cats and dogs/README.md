# Cats vs Dogs Classification

Image classification project using PyTorch and transfer learning.

## Model

- VGG19_BN
- Transfer Learning
- RMSProp optimizer
- CrossEntropyLoss

## Features

- Modular project structure
- Separate train/inference pipelines
- Checkpoint saving
- Validation metrics
- GPU support
- Training visualization
